### AI & Machine Learning
On the AI Engineer channel, Dat Ngo details the architecture of LLM evaluations in **[LLM Observability, Evaluation, Experimentation Platform](https://www.youtube.com/watch?v=JsCCrBF7F1g)**. He emphasizes the use of OpenTelemetry (OTel) traces to audit agents across granular spans, multi-span trajectories, and full session scopes, noting that code alone can no longer effectively audit non-deterministic models. The talk also breaks down the nuances of using LLM-as-a-judge versus deterministic code evals to measure signal without relying entirely on human intervention.
