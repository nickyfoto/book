# Company@X — 2026-07-20

This move signals that guaranteed compute access has become just as critical as capital for accelerating frontier research and AI-native companies. 

## Key Announcements

**NVIDIA** · [Source](http://twitter.macworks.dev/NVIDIAAI/status/2079236204743053592#m)
NVIDIA launched Cosmos 3 Edge, a fully open, on-device frontier world model aimed at robotics, autonomous vehicles, and vision AI. The model features 4B parameters paired with a 2B Nemotron-based reasoner, capable of running on edge hardware like DGX Spark and NVIDIA Jetson. By open-sourcing the weights, post-training recipes, and code on Hugging Face, NVIDIA continues to commoditize the edge intelligence layer to drive hardware adoption.

**Pulse AI** · [Source](http://twitter.macworks.dev/sid_mnk/status/2079257382304260407#m)
Pulse AI successfully deployed agentic payments, enabling AI agents to independently pay for API endpoint access without requiring an account or API key. Using the Machine Payments Protocol (MPP), the system relies on the historically reserved HTTP 402 "Payment Required" status code to settle transactions inline using USDC. This introduces a fundamental missing primitive for the autonomous, machine-to-machine economy.

**x.ai** · [Source](http://twitter.macworks.dev/grok/status/2079233333893185876#m)
Grok for Excel is now live, powered by the newly referenced Grok 4.5 model. The integration focuses on complex enterprise workflows, allowing users to build financial models, analyze market data, and generate charts directly within spreadsheets. 

**Neo Security** · [Source](http://twitter.macworks.dev/a16z/status/2079222562807005369#m)
Neo emerged from stealth with a $100M Seed round led by a16z, pioneering "agentic software control". Founded by veteran SentinelOne executives, the company is building security infrastructure for a new reality where AI agents operate on endpoints with the full privileges of the humans they serve, a shift that breaks traditional Zero Trust and EDR paradigms.

**Anthropic** · [Source](http://twitter.macworks.dev/AnthropicAI/status/2079256626771665098#m)
Anthropic officially launched its AI for Science program, beginning with up to $50,000 in Claude usage grants. The initial capital is explicitly targeted at researchers utilizing Claude to accelerate cures for rare diseases, highlighting Anthropic's strategic push to embed its models into rigorous scientific and biomedical workflows.
