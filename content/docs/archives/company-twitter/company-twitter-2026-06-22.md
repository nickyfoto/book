# Company@X — 2026-06-22

## Signal of the Day
Google has officially moved its Interactions API into general availability, establishing it as the primary developer interface for Gemini models and marking a definitive shift away from simple chat completion toward stateful, agentic AI. The API introduces native support for Managed Agents, background execution, and expanded tool use, while formally teasing the impending launch of "Gemini Omni".

## Key Announcements

**Google** · [Source](http://twitter.macworks.dev/Google/status/2069108942102310957#m)
Google’s release of the Interactions API provides the architectural foundation for delegating complex, real-world workflows to agents. By optimizing for background execution and stateful memory, Google is directly enabling the automated administrative and engineering tasks that enterprises demand, signaling that autonomous AI is ready for production. 

**xAI** · [Source](http://twitter.macworks.dev/grok/status/2069095154691272933#m)
xAI introduced a new `/goal` command within Grok Build, enabling the system to autonomously execute long-running tasks by deploying multiple rounds of subagents for implementation and verification. In a simultaneous push into fintech, xAI launched an integration with Interactive Brokers, allowing Grok to fetch high-quality, real-time portfolio data to assist with investment research, though users must still approve every trade.

**Cursor** · [Source](http://twitter.macworks.dev/cursor_ai/status/2069149296436330776#m)
During a keynote at Compile, the AI-native code editor Cursor announced it is training a new model in direct collaboration with SpaceX. This partnership highlights Cursor's strategic move to tailor models for highly complex, specialized engineering environments beyond standard software development.

**Google DeepMind** · [Source](http://twitter.macworks.dev/GoogleDeepMind/status/2069066675895337405#m)
Google DeepMind unveiled a research partnership with independent entertainment studio A24. The alliance is a strategic maneuver to co-develop the next generation of creative tools, ensuring that generative AI workflows are shaped directly by high-tier industry creators.

**a16z** · [Source](http://twitter.macworks.dev/a16z/status/2069054233702449425#m)
a16z led a $30M Series A in Prosper AI, a platform designed to automate the voice-heavy operational load for medical clinics. Prosper handles end-to-end patient workflows—including scheduling, insurance verification, and billing—and has already secured 150,000 healthcare providers and major EHR integration with Athenahealth.
