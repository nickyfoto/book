## Top Stories

**[Apple’s Smart Glasses Delayed Over Privacy](https://apple.slashdot.org/story/26/07/26/2022231/apples-smart-glasses-delayed-as-engineers-consider-privacy-concerns)** · Slashdot
Apple is pushing the consumer release of its first smart glasses to late 2027, though a WWDC reveal is still planned for June of that year. The engineering and marketing teams are taking extra time to address privacy concerns, actively debating whether the glasses should feature cameras capable of video recording or if they should be limited to object recognition and on-device processing to protect bystanders. 

**[Decade-Old Vulnerability Rocks FFmpeg](https://www.infoq.com/news/2026/07/pixelsmash-vulnerability/)** · InfoQ
Security researchers have disclosed "PixelSmash," a critical vulnerability (CVE-2026-8461) in the ubiquitous FFmpeg media framework that has gone unnoticed in the codebase for 16 years. The flaw allows attackers to achieve remote code execution simply by delivering a 50 KB crafted media file to any vulnerable application, impacting everything from desktop video players to self-hosted media servers and cloud transcoding pipelines.

**[Huawei Rumored to Build Domestic DRAM Fab](https://hardware.slashdot.org/story/26/07/26/0613242/is-huawei-building-its-own-dram-fab)** · Slashdot
Huawei has reportedly partnered with state-backed DRAM manufacturer SwaySure to set up a 12-inch memory production plant in Shenzhen. Driven by US export controls that restrict Chinese entities from acquiring high-bandwidth memory from global suppliers like Samsung, Huawei is attempting to secure a captive HBM supply for its own Ascend AI accelerators.

**[Amazon EKS Solves Kubernetes Rollbacks](https://www.infoq.com/news/2026/07/eks-version-rollback/)** · InfoQ
Amazon EKS has introduced a feature allowing operations teams to roll back a cluster's Kubernetes control plane to a previous version within seven days of an upgrade. This native capability safely reverts the API server while preserving workloads and data, eliminating the need for expensive, time-consuming workarounds like blue/green deployments that teams previously relied on to safely patch systems.

**[Google Loses Anti-Scraping Case Against SerpApi](https://yro.slashdot.org/story/26/07/26/1939229/googles-anti-search-scraping-lawsuit-dismissed)** · Slashdot
A US district court has dismissed Google's DMCA lawsuit against SerpApi over the scraping of search results, ruling there was no proof that copyright holders authorized Google to take action. The ruling is a significant win for open data access, pushing back on Google's attempt to use copyright law to restrict others from utilizing the exact same web-scraping techniques that built its own search empire.
