# Tech Videos — 2026-08-16

## Watch First
The standout recommendation today is **[Anthropic’s co-founder on using Claude effectively](https://www.youtube.com/watch?v=kaFiNLiIPpQ)** on Lenny's Podcast. It delivers a highly practical, non-obvious engineering insight: when an LLM fails at a coding task, completely discarding the broken output and starting fresh with a new prompt has a significantly higher success rate than trying to debug and bang on the same error.

## Highlights by Theme

### Developer Tools & Platforms
In **[OpenAI’s Head of Design: This is the best time in history to be a designer | Ian Silber](https://www.youtube.com/watch?v=BV0hy6NET-U)** on Lenny's Podcast, Ian Silber explains how coding agents like Codex and ChatGPT have compressed the traditional, slow design loop into minutes, allowing rapid software prototyping. Silber mentions utilizing tools like voice mode and computer use internally for building software, while highlighting the developer utility of **WorkOS** drop-in APIs for enterprise features like SSO and RBAC.

### AI & Machine Learning
In **[Anthropic’s co-founder on using Claude effectively](https://www.youtube.com/watch?v=kaFiNLiIPpQ)** on Lenny's Podcast, the co-founder advises developers to move past basic autocomplete and simple chat to demand ambitious architectural changes from models like Claude. He emphasizes that if an AI-generated solution fails, the most reliable path to success is completely clearing the context and starting over rather than continuously prompting to fix the buggy code. Additionally, Ian Silber in **[OpenAI’s Head of Design: This is the best time in history to be a designer | Ian Silber](https://www.youtube.com/watch?v=BV0hy6NET-U)** argues that today's models already function as incredibly capable product designers, shifting the human developer and designer role towards high-level curation, custom intent expression, and complex systems thinking.
