# Engineering Reads — 2026-09-15

## The Big Idea
Engineers frequently fail to communicate technical ideas effectively because they focus on slide production rather than building a coherent narrative. Successful technical communication requires **distilling the core idea**, **visualizing the target audience**, and **constructing a structured storyline** before designing visual artifacts.

## Deep Reads

**[Nail the Narrative](https://martinfowler.com/articles/never-send-slides/nail-your-narrative.html)** · Sumeet Gayathri Moghe · [martinfowler.com](https://martinfowler.com/articles/never-send-slides/nail-your-narrative.html)
When technical presentations fail to convince or align teams, the root cause is typically a missing underlying narrative structure rather than insufficient slide content. Sumeet Gayathri Moghe observes that creators regularly get tangled in slide mechanics without first establishing a clear, governing narrative flow. To overcome this, authors must distill their core proposal into a single **big idea**, map out the audience's mental model, and deliberately build a **structured storyline**. This approach trades immediate slide output for upfront narrative engineering, avoiding the common failure mode of delivering detailed technical information that fails to drive decisions. Staff engineers, technical leads, and software architects preparing proposals or design reviews should read this to refine how they structure complex technical arguments for decision-makers.
