# Company@X — 2026-04-11

## Signal of the Day
Cursor officially introduced Cursor 3, a development environment explicitly built for a new paradigm where AI agents write all code. To accelerate this shift, the company has completely removed hourly limits and doubled Composer 2 usage in their new interface. 

## Key Announcements

**OpenAI** · [Source](http://twitter.macworks.dev/OpenAI/status/2042780052669239782#m)
OpenAI is mandating security updates for its macOS applications following a broader industry security incident involving the third-party developer library Axios. While the company verified that no user data was accessed and internal systems were not compromised, they are actively recertifying their macOS apps to prevent the potential distribution of fake, malicious software. Users must update to the latest versions of ChatGPT Desktop, the Codex App, Codex CLI, and Atlas to ensure safe access.

**Google Cloud** · [Source](http://twitter.macworks.dev/GoogleCloudTech/status/2042996096578765248#m)
Google Cloud launched the GKE Inference Gateway to help engineering teams run both real-time and asynchronous AI inference on a single, unified infrastructure. This architectural release streamlines deployments for modern AI services by natively bridging the operational gap between low-latency user requests and heavy background batch processing tasks.

**OpenClaw** · [Source](http://twitter.macworks.dev/openclaw/status/2042811598058742012#m)
OpenClaw shipped version 2026.4.10, headlined by a new Active Memory plugin and a localized MLX Talk mode. The update also focuses heavily on enterprise security and integrations, delivering Server-Side Request Forgery (SSRF) hardening, a Codex app-server harness plugin, and Microsoft Teams integration for pins, reactions, and read actions.

**OpenAI** · [Source](http://twitter.macworks.dev/thsottiaux/status/2043075353242218768#m)
OpenAI issued a public correction regarding the rate limits on its $100 and $200 Pro plans, clarifying that the tiers respectively provide 10x and 40x the capacity of ChatGPT Plus until May 31. The company admitted that poor messaging on their pricing page mixed up baseline allowances with a temporary 2x promotional boost, causing widespread confusion among heavy API and chat users.
