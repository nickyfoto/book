# Company@X — 2026-05-16

## Signal of the Day
xAI has integrated X Premium subscriptions and live X platform search into NousResearch's Hermes Agent. This signals a strategic push by xAI to expand its developer ecosystem beyond native Grok interfaces, embedding its real-time data moat directly into popular open-weight agent frameworks.

## Key Announcements

**xAI** · [Source](http://twitter.macworks.dev/xai/status/2055745332919808181#m)
xAI announced that users can now utilize their X Premium subscriptions natively within the Hermes Agent. Furthermore, the Hermes Agent has been granted capabilities to search X posts directly. This integration connects xAI's proprietary real-time data access into a broader ecosystem of open-source agent tools, increasing the utility of X Premium for power users and developers.

**GBrain / Garry Tan** · [Source](http://twitter.macworks.dev/garrytan/status/2055670533451366479#m)
Garry Tan highlighted the launch of "GBrain," a new open-source knowledge system featuring an eight-layer memory architecture for AI agents. Distinct from standard "RAG in a box," the system is designed to seamlessly integrate with models like OpenClaw or Hermes Agent, providing them with deep contextual awareness of the user. This architectural move underscores the growing industry focus on long-term agentic memory as the key hurdle to unlocking highly capable personal AI.

**a16z** · [Source](http://twitter.macworks.dev/a16z/status/2055447056995791233#m)
Andreessen Horowitz highlighted mounting data showing measurable productivity lifts across industries identified as "high-AI". This data point reinforces the narrative that enterprise adoption of AI tooling is moving past speculative pilot programs into measurable, operational efficiency gains at scale.
