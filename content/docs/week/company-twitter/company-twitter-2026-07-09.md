# Company@X — 2026-07-09

## Signal of the Day
OpenAI dramatically expanded its agentic capabilities with the launch of the GPT-5.6 model family and a new autonomous agent dubbed "ChatGPT Work." This release signals a definitive pivot from conversational AI toward long-running, multi-app workflows capable of executing complex professional tasks across web and desktop environments.

## Key Announcements

**OpenAI** · [Source](http://twitter.macworks.dev/OpenAI/status/2075274271845404744#m)
OpenAI launched its GPT-5.6 family (Sol, Terra, Luna) alongside ChatGPT Work, an autonomous agent powered by Codex that takes action across user apps and files. GPT-5.6 introduces an "ultra mode" for coordinating parallel subagents on demanding tasks and claims state-of-the-art performance on the Artificial Analysis Coding Agent Index, beating Anthropic's Claude Fable 5. The move effectively integrates Codex directly into the ChatGPT desktop app, positioning it as an enterprise workflow engine.

**Meta** · [Source](http://twitter.macworks.dev/AIatMeta/status/2075221088821518394#m)
Meta introduced Muse Spark 1.1, a multimodal reasoning model optimized for orchestrating multi-agent systems and multi-app computer-use workflows. Accompanying the release is the public preview of the new Meta Model API, marking the first time Meta is hosting its own model API. The model reportedly operates at a fraction of the cost and latency of competitors like Opus 4.8 and GPT 5.5, while automating model development tasks for Meta's internal research teams.

**Google Cloud** · [Source](http://twitter.macworks.dev/googlecloud/status/2075251885276012668#m)
Google Cloud announced the general availability of AlphaEvolve, a Gemini-powered evolutionary agent co-developed with DeepMind that autonomously designs optimized code. Concurrently, Google rolled out infrastructure for executing agentic actions, including managed Model Context Protocol (MCP) servers and Cloud Run sandboxes in preview. This establishes a secure runtime environment for enterprises to deploy untrusted, AI-generated code and automate internal operations.

**NVIDIA** · [Source](http://twitter.macworks.dev/NVIDIARobotics/status/2074380795855147072#m)
NVIDIA Robotics expanded its open physical AI tools by bringing GR00T 1.7 to HuggingFace's LeRobot ecosystem. The release of this open Vision-Language-Action (VLA) model for humanoid robots alongside Isaac Teleop makes frontier physical AI accessible to a much broader base of developers.

**Anthropic** · [Source](http://twitter.macworks.dev/AnthropicAI/status/2075257492716879967#m)
Anthropic appointed former Federal Reserve Chair Dr. Ben Bernanke to its Long-Term Benefit Trust. This governance move highlights Anthropic's strategy of bringing high-profile, institutional macroeconomic expertise to oversee its long-term societal impacts.

**Ollama** · [Source](http://twitter.macworks.dev/ycombinator/status/2075271225262432442#m)
Ollama announced a $65M Series B funding round, revealing it now serves 9 million active developers and 85% of the Fortune 500. The 14-person company has rapidly become the de facto platform for developers running open-source AI models locally.
