## Key Announcements

**[AWS]** · [Source](http://twitter.macworks.dev/awscloud/status/2055337708734603381#m)
AWS shared year-one metrics for AWS Transform, its agentic AI service for enterprise migration, revealing that the tool analyzed 4.56 billion lines of code and saved teams 1.69 million hours of manual effort. AWS also signaled the platform's future roadmap, which will include full-stack Windows and mainframe coverage, multi-surface access, and a new Agent Builder designed to help enterprises scale their internal playbooks.

**[Microsoft]** · [Source](http://twitter.macworks.dev/HuggingPapers/status/2055176632491778363#m)
Microsoft has released Lens, a new 3.8-billion parameter text-to-image model available on Hugging Face. The model provides highly efficient training capabilities and supports high-resolution image generation up to 1440x1440. 

**[xAI]** · [Source](http://twitter.macworks.dev/grok/status/2055332476365443381#m)
Grok is moving aggressively into enterprise workflows, launching three new connectors that allow the AI to interface directly with Microsoft Teams, Salesforce, and Box. The Box integration specifically provides Grok Business users with secure, permissions-aware access to internal corporate content. Furthermore, users can now plug their Grok subscriptions directly into the NousResearch Hermes Agent.

**[Google Cloud]** · [Source](http://twitter.macworks.dev/GoogleCloudTech/status/2055413087327363282#m)
Google Cloud detailed the networking infrastructure behind its TPU 8t rack-level connectivity to the Virgo fabric. The architecture utilizes high-radix switches to reduce network layers, operating on a flat, two-layer non-blocking topology. Separately, Google Cloud rolled out QueryData for AlloyDB, a system allowing developers to query complex databases using natural language and high-speed vector search.

**[OpenClaw]** · [Source](http://twitter.macworks.dev/openclaw/status/2055437760459055405#m)
The open-source agent framework OpenClaw dropped a new release that is roughly 3.5x faster, backed by continuous end-to-end RTT tests over real message channels to prevent silent regressions. The update also ships with strict new security guardrails, including root-bounded filesystem controls (fs-safe), policy-driven network egress routing (Proxyline), and smarter command approvals.

**[Tsinghua / Open Source AI]** · [Source](http://twitter.macworks.dev/stingning/status/2055123219506725201#m)
A new 30B-A3B reasoning model was released on Hugging Face, utilizing a unified scaling recipe tailored for proof search. According to the release, the model hits gold-medal performance across major physics and math Olympiad evaluations, solving IPhO natively and passing IMO/USAMO benchmarks via test-time self-verification and refinement.
