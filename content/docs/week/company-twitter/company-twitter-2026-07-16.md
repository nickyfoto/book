# Company@X — 2026-07-16

## Signal of the Day
Google has officially rebranded its breakout hit NotebookLM to "Gemini Notebook," signaling its deeper integration into Google Search and the Gemini app ecosystem. Crucially, the platform is rolling out a secure cloud computer for every notebook, evolving the product from an AI reading companion into an active execution environment capable of natively writing and running code for complex data analysis.

## Key Announcements

**Google** · [Source](http://twitter.macworks.dev/Google/status/2077786615800295712#m)
Google Workspace rolled out Gemini Omni and personal avatars to Google Vids, allowing users to generate high-quality video clips, swap backgrounds, and execute step-by-step edits using conversational prompts. The rollout coincides with Google's natively multimodal Gemini Omni Flash debuting at the #1 spot on the Artificial Analysis Leaderboards for both Text-to-Video and Image-to-Video, edging out ByteDance's Seedance 2.0.

**xAI** · [Source](http://twitter.macworks.dev/grok/status/2077860594557001813#m)
Grok launched "Automations," a major new capability allowing users to describe a job, set a schedule or trigger, and have Grok run it autonomously and report back. Alongside this shift toward agentic scheduling, xAI also announced that the Grok 4.5 model is now fully available to users across Europe.

**Thinking Machines** · [Source](http://twitter.macworks.dev/thinkymachines/status/2077454609551921208#m)
Thinking Machines released "Inkling," a massive 975B parameter open model that natively supports image, audio, and text with a 1M token context window. The AI community has already quantized the model to dynamic 1-bit, reducing its size by 86% so it can run on 280GB of memory while retaining 74.2% of its accuracy.

**Sable AI** · [Source](http://twitter.macworks.dev/Nim_Ravid1/status/2077785419912188236#m)
Nim Ravid announced the launch of "Aidan," positioned as the first computer-using AI built specifically for real-time conversation. Backed by a new $45M raise from Sequoia and 8VC, Aidan is already deployed by Notion and Decagon AI to autonomously run live sales demos and customer onboarding interactions.

**Runta** · [Source](http://twitter.macworks.dev/guanlan/status/2077777618829820191#m)
Andreessen Horowitz led a $20M seed round for Runta, an execution layer platform designed specifically for the AI agent ecosystem. Runta acts as a secure computer that enforces policy controls, ensuring autonomous agents can run securely and efficiently within restricted enterprise environments.
