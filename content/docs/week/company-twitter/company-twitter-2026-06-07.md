# Company@X — 2026-06-07

## Signal of the Day
The `llama.cpp` inference framework has officially merged support for Gemma 4's Multi-Token Prediction (MTP). This integration represents a major step forward for local AI deployments, allowing developers to combine Quantization-Aware Training (QAT) with MTP to run complex models at the edge with significantly faster processing speeds and lower hardware requirements. 

## Key Announcements

**[llama.cpp / Hugging Face]** · [Source](http://twitter.macworks.dev/osanseviero/status/2063676865441665426#m)
Gemma 4's MTP architecture has been officially integrated into the popular `llama.cpp` repository. This allows developers and researchers to leverage Gemma 4 QAT alongside MTP, delivering a lightweight, highly optimized setup for local execution. The development highlights the industry's continued momentum toward high-performance, low-latency models that bypass the need for cloud compute.
