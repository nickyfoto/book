# Company@X — 2026-03-29

## Signal of the Day
OpenClaw released version 2026.3.28, introducing a vital security primitive that enables plugins to pause for user approval using `before_tool_call` hooks. This provides developers with an essential interactive "firewall" for tool calls, addressing a crucial UX and safety barrier in autonomous agent development.

## Key Announcements

**OpenClaw** · [Source](http://twitter.macworks.dev/openclaw/status/2038084923517796839#m)
Alongside the new approval hooks, OpenClaw's Tokyo pre-ClawCon drop integrates the xAI Responses API and `x_search`. Contributors note ongoing efforts to optimize the routing between X Search, web search, and Grok's code execution, signaling a push for more dynamic and intelligent multi-modal tool orchestration. The release also includes an ACP bind for Discord and iMessage.

**Google Cloud** · [Source](http://twitter.macworks.dev/GoogleCloudTech/status/2038330351693480102#m)
Google published a new workflow detailing the supervised fine-tuning (SFT) process for Gemini 2.5 Flash using the Vertex AI SDK for Python. The update focuses on allowing developers to improve model performance on specific tasks while minimizing the associated infrastructure overhead.

**Google Cloud** · [Source](http://twitter.macworks.dev/GoogleCloudTech/status/2038375648306057440#m)
Google is utilizing the Model Context Protocol (MCP) alongside Dev Skills to inject ADK expertise directly into developer IDEs. This approach aims to eliminate coding hallucinations by strictly grounding the AI assistant in the latest framework best practices.
