# Company@X — 2026-05-24

## Signal of the Day
OpenClaw launched version 2026.5.22, significantly reducing model startup latency to ~5ms and aggressively hardening supply chain security across npm and Windows installations. This marks a strong push toward production-grade reliability and lightning-fast local execution for AI tooling.

## Key Announcements

**OpenClaw** · [Source](http://twitter.macworks.dev/openclaw/status/2058397616124072274#m)
Released version 2026.5.22 with leaner gateway/model startup paths, bringing model invocation times down to roughly 5ms. The update heavily emphasizes infrastructure security by shipping locked dependencies, generating shrinkwraps for npm plugins, and hardening Windows bootstrap paths with safe shims and rollback capabilities. 

**Y Combinator** · [Source](http://twitter.macworks.dev/sdianahu/status/2058644733677986223#m)
Confirmed that its S26 extended deadline is closing alongside an experimental $2M OpenAI offer for early-stage startups. This massive credit bundle signals the sheer scale of compute now required to bootstrap competitive "0->1" AI-native companies, though YC remains uncertain if this specific offer structure will be repeated.

**Hugging Face (LongCat)** · [Source](http://twitter.macworks.dev/victormustar/status/2058492201261244458#m)
Highlighted the release of an MIT-licensed, open-source talking-avatar model by LongCat, which is currently yielding state-of-the-art results. This allows developers to build visual AI tutors, dubbing pipelines, and talking-head coding agents locally or via free Hugging Face Spaces without proprietary API lock-in.

**Hugging Face** · [Source](http://twitter.macworks.dev/ClementDelangue/status/2058672394865111544#m)
Announced that `llama.cpp` now features MTP (Multi-Token Prediction) support, dramatically increasing local inference speeds. Dense generation for models like Qwen3.6-27B on an A10G jumped from 25 to 45 tokens per second (+78%), making open-weight local models viable as fast daily drivers.

**Tesla** · [Source](http://twitter.macworks.dev/Tesla/status/2058638532353434023#m)
Revealed a native vehicle integration leveraging Grok as an in-car local guide. Drivers can now use voice commands ("Hey Grok") to query geological features and local history while operating the vehicle in Full Self-Driving (FSD) Supervised mode.
