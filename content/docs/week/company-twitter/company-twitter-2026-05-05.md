# Company@X — 2026-05-05

## Signal of the Day
OpenAI fundamentally upgraded the baseline ChatGPT experience by rolling out GPT-5.5 Instant as the default model for all users, deploying it simultaneously to the API alongside new memory and personalization architecture. 

## Key Announcements

**OpenAI** · [Source](http://twitter.macworks.dev/OpenAI/status/2051709035347694047#m)
OpenAI is rolling out GPT-5.5 Instant as the default model for all ChatGPT users and as `gpt-5.5-chat-latest` in the API. The upgrade delivers significant improvements in factuality for high-stakes domains like medicine, law, and finance, while improving performance on everyday tasks. Concurrently, OpenAI is deploying enhanced memory and personalization features that draw context from saved chats, files, and connected Gmail accounts, providing users with visible citations for memory sources.

**xAI** · [Source](http://twitter.macworks.dev/xai/status/2051703217697010103#m)
xAI launched Grok 4.3 on its API, featuring a 1-million-token context window and aggressive pricing at $1.25 per million input tokens and $2.50 per million output tokens. Positioned as xAI's fastest and most intelligent model, Grok 4.3 reportedly tops leaderboards in agentic tool calling and instruction following, taking the number one spot in enterprise domains like corporate finance and case law.

**Google** · [Source](http://twitter.macworks.dev/googleaidevs/status/2051734539085455542#m)
Google significantly upgraded the Gemini API File Search tool for developers building multimodal RAG systems. Utilizing the Gemini Embedding 2 model, the system can now reason across images and text simultaneously, filter unstructured data via custom key-value metadata tags, and return exact citations down to specific page numbers. On the enterprise side, Google Cloud introduced Agent Gateway to provide secure, centralized air-traffic control and policy enforcement for corporate agent fleets.

**Anthropic** · [Source](http://twitter.macworks.dev/AnthropicAI/status/2051758528562364902#m)
Anthropic Fellows published new research on Model Spec Midtraining (MSM), a training phase that teaches AI models to understand their governing constitution before undergoing standard alignment training. This technique was developed to counter the threat of "sandbagging"—where capable models strategically hide their abilities from weaker supervisors—and empirical results show MSM drastically reduces unsafe actions in agentic settings. 

**Cursor** · [Source](http://twitter.macworks.dev/cursor_ai/status/2051739625958584659#m)
Cursor shipped a major workflow automation feature that allows the editor to automatically fix Continuous Integration (CI) failures. Developers can deploy always-on agents that monitor GitHub repositories, investigate the root causes of broken builds, and automatically open pull requests with the necessary code fixes.

**Andreessen Horowitz (a16z)** · [Source](http://twitter.macworks.dev/a16z/status/2051674423837753552#m)
Andreessen Horowitz announced a $2.2 billion Crypto Fund 5 targeting new on-chain infrastructure and products, citing stabilizing regulations and the movement of capital markets on-chain. The firm also announced it led a $60 million Series A in Tessera Labs, an AI-native system integrator aiming to compress enterprise ERP software transformations from years down to weeks, beginning with SAP upgrades.

**Microsoft** · [Source](http://twitter.macworks.dev/satyanadella/status/2051712533174931707#m)
Microsoft expanded its Copilot Cowork agent platform to iOS and Android, allowing users to delegate complex tasks from mobile devices and pick them up seamlessly on desktop. The update ships alongside new skills and plugins that enable Cowork to operate autonomously across disconnected business systems and corporate data.
