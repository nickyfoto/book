# Company@X — 2026-06-16

## Signal of the Day
SpaceX has acquired the AI coding platform Cursor in an all-stock transaction to accelerate its frontier AI capabilities. The two companies have been jointly training a new model that will be released soon in both Cursor and Grok Build, signaling a massive vertical integration play that pairs the fastest-growing developer interface with SpaceX and xAI's infrastructure. 

## Key Announcements

**[SpaceX]** · [Source](http://twitter.macworks.dev/SpaceX/status/2066873915717136548#m)
SpaceX formally announced its acquisition of Cursor to build the "world’s most useful AI models". Over the last few months, SpaceXAI and Cursor have been jointly training a proprietary model that will integrate directly into Cursor and the upcoming Grok Build. This strategic consolidation directly challenges Microsoft's GitHub Copilot dominance by bringing a premier AI coding tool in-house.

**[Cursor]** · [Source](http://twitter.macworks.dev/cursor_ai/status/2067012220832329782#m)
In tandem with the acquisition, Cursor is launching "Origin," a native code storage and git hosting solution aimed at teams and autonomous agents. Available this fall, Origin provides a dedicated environment to host, review, and collaborate on code, positioning Cursor as a full-stack alternative to traditional Git providers rather than just a localized IDE.

**[Google Cloud]** · [Source](http://twitter.macworks.dev/GoogleCloudTech/status/2067012903337664886#m)
Google Cloud introduced the Open Knowledge Format (OKF), a vendor-neutral specification designed to standardize the "LLM-wiki pattern" for enterprise AI agents. OKF allows organizations to package context—using standard markdown, files, and YAML frontmatter—into a highly portable format that can be hosted in git repos or natively ingested by tools like Google's Knowledge Catalog. This addresses a major bottleneck in agent development by making organizational context structurally interoperable rather than fragmented across bespoke integrations.

**[Google]** · [Source](http://twitter.macworks.dev/Google/status/2066956270179848329#m)
Google began rolling out Android 17 and Wear OS 7 to eligible Pixel devices. Android 17 introduces "Bubbles" for floating-window multitasking and new foldable gaming modes, while Wear OS 7 brings Android Live Updates to the wrist and lays the groundwork for system-level Gemini Intelligence integration coming later this year. 

**[Coinbase]** · [Source](http://twitter.macworks.dev/coinbase/status/2066969129110630667#m)
Coinbase launched Coinbase Advisor, which it claims is one of the world's first AI agents officially registered with the SEC as an investment advisor. Rolling out to Coinbase One members, the agent has complete context of a user's portfolio and account history, enabling natural language interactions to execute trades, conduct portfolio analysis, and automate tax loss harvesting.

**[OpenAI]** · [Source](http://twitter.macworks.dev/OpenAI/status/2066969635099144682#m)
OpenAI detailed a new "Deployment Simulation" research method designed to evaluate candidate models using de-identified, real-world user requests before public release. By analyzing candidate responses against baseline predictions across 20 behavior categories, the simulation helps estimate real-world error rates and surface unpredicted agentic behaviors more accurately than traditional red-teaming alone. Concurrently, OpenAI is expanding the rollout of its Codex model, including the Chrome extension and "Computer use" capabilities, to users in the EEA, UK, and Switzerland.

**[Zai_org]** · [Source](http://twitter.macworks.dev/Designarena/status/2066940737011560652#m)
The newly released GLM-5.2 model achieved the #1 spot on Design Arena, securing an Elo of 1360 and surpassing Claude Fable 5. The open-weights model features a 1M token context window and utilizes a new IS attention mechanism for greater efficiency, demonstrating reasoning performance comparable to Opus 4.8.

**[Harvey]** · [Source](http://twitter.macworks.dev/MollySOShea/status/2066889824749891974#m)
Legal AI platform Harvey surpassed $300M ARR this month, effectively tripling its revenue since last August. The $11 billion Sequoia-backed company now serves nearly 2,000 customers—including two-thirds of the AmLaw 100—and has seen daily active usage jump to 52%, processing a projected 13 trillion tokens this month.
