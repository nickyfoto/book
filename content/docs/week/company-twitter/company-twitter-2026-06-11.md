# Company@X — 2026-06-11

## Signal of the Day
The most significant indicator of the emerging machine-to-machine economy is Coinbase's launch of "Coinbase for Agents," which equips autonomous AI models with their own on-chain accounts. By actively standardizing the infrastructure for agentic finance, Coinbase is allowing AI systems to execute portfolio trades, run autonomously under guardrails, and pay for data and research tools via the upcoming x402 integration.

## Key Announcements

**[xAI]** · [Source](http://twitter.macworks.dev/xai/status/2065099299541893577#m)
xAI rolled out the Grok Build Plugin Marketplace in beta, shifting its interface into an orchestrated developer hub. Developers can now operate directly from their terminal to leverage tools like Vercel, MongoDB, Sentry, and Cloudflare, allowing their AI agents to spin up sandboxes, optimize databases, and autonomously triage system alerts.

**[Google Cloud]** · [Source](http://twitter.macworks.dev/GoogleCloudTech/status/2065141979399287074#m)
Google released the open-source Data Agent Kit, pushing for highly interoperable, cross-platform agent workflows. This unified collection of data engineering and science skills integrates directly into environments developers already use, such as VS Code, Claude Code, and Google's own multi-agent orchestration framework, the Antigravity CLI.

**[Cursor]** · [Source](http://twitter.macworks.dev/cursor_ai/status/2065137803084857845#m)
Cursor has activated its agent auto-review as the default security setting for all new users. Driven by a classifier subagent with 97% accuracy, the tool evaluates AI-generated actions in context to automatically allow, block, or mandate human approval, highlighting critical maturation in production-grade AI scaffolding.

**[XiaomiMiMo]** · [Source](http://twitter.macworks.dev/XiaomiMiMo/status/2063993799085633911#m)
XiaomiMiMo successfully open-sourced the weights for a 1-trillion parameter model that achieves over 1,000 tokens per second on a single, standard 8-GPU node. The major performance milestone bypasses the need for specialized ASICs by utilizing FP4 quantization and a block-masked parallel speculative decoding technique called DFlash to drastically reduce memory traffic.

**[Arcee AI]** · [Source](http://twitter.macworks.dev/arcee_ai/status/2064336668341973445#m)
Arcee AI finalized a multi-million-dollar strategic partnership with Hugging Face. In a major consolidation move, the Hugging Face Hub will serve as the exclusive host for all of Arcee's output, encompassing every open model, proprietary dataset, private run, and agent trace they build.

**[Kapa]** · [Source](http://twitter.macworks.dev/emilsnotes/status/2065089987935105103#m)
Kapa officially introduced Kapa for Agents, deploying an API and Retrieval Model Context Protocol (MCP) to supply production-ready agents with vital corporate knowledge. Intended to prevent AI systems like Claude Code from encountering dead ends during complex tasks, the platform connects over 30 data sources in real-time to drastically enhance agentic planning.

**[Google]** · [Source](http://twitter.macworks.dev/Google/status/2065073209171480599#m)
Google is widening the footprint of Gemini in Chrome, bringing the capability to more desktop and iOS users throughout Latin America, Africa, and the Middle East. The expansion integrates Workspace applications directly into the browser without leaving the page and rolls out Nano Banana 2 for text-to-image transformations.
