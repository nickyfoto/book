# Company@X — 2026-07-03

## Signal of the Day
AWS announced a fundamental architectural shift for Alexa, re-platforming the world's most widely used personal assistant on Amazon Bedrock. This integration of massive device distribution with frontier models represents one of the largest consumer deployments of agentic capabilities in the market.

## Key Announcements

**Google DeepMind** · [Source](http://twitter.macworks.dev/TZahavy/status/2070300619257106819#m)
DeepMind's Discovery team launched COrigami, an end-to-end pipeline that co-designs physical origami alongside Gemini. The system uses self-improving reinforcement learning to convert abstract JSON into mathematically grounded, flat-foldable SVG crease patterns. This approach proves that combining frontier models with visual feedback loops can successfully execute physical design tasks despite severely constrained training data.

**Hugging Face** · [Source](http://twitter.macworks.dev/Thom_Wolf/status/2072057144996921398#m)
The Hugging Face AI x Science team released Multimodal Universe, a massive 80-terabyte astrophysics dataset aggregating over 30 sources of galaxy imagery, spectra, and variable star time series. Using advanced cross-matching capabilities, researchers can now query 800,000 SDSS objects against 122 million Gaia objects entirely on a local laptop using just ~4GB of RAM. 

**Browser Use** · [Source](http://twitter.macworks.dev/gregpr07/status/2072821514433712405#m)
Browser Use shipped CLI 3.0, a tool allowing developers to turn any model into a state-of-the-art browser agent. The newly streamlined agent is six times smaller, uses fewer tokens, and can execute tasks via direct Chrome DevTools Protocol (CDP) on both cloud and local browsers.

**LlamaIndex** · [Source](http://twitter.macworks.dev/jerryliu/status/2073116662602342734#m)
After 500,000 hours of beta usage, Jerry Liu officially launched Dayflow, an open-source automatic work journal. Driven by screen data context, Dayflow aims to provide a factual audit of user time allocation to counter the unreliability of manual calendars and human memory.

**Hugging Face & Cerebras** · [Source](http://twitter.macworks.dev/Thom_Wolf/status/2072825424800006350#m)
Hugging Face partnered with Cerebras to launch a fully open-source, real-time speech-to-speech voice AI demo. By providing the models and code openly, the release underscores the rapidly shrinking gap between proprietary voice models and the open-source ecosystem.
