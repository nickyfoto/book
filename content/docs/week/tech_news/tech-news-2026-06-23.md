**[29-Year-Old 'Squidbleed' Bug Exposes Cleartext Traffic](https://it.slashdot.org/story/26/06/23/2025211/29-year-old-squid-proxy-bug-squidbleed-can-leak-cleartext-http-requests)** · Slashdot
Security researchers have unearthed a critical vulnerability in the widely used Squid web proxy that has been hiding in plain sight for nearly three decades. Dubbed "Squidbleed," the flaw allows an authorized user on a shared network to retrieve fragments of other users' cleartext HTTP requests, including session tokens and credentials, by exploiting a bug tied to Squid's default FTP gateway.
