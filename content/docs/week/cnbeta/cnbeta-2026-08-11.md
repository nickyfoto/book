# CNBeta — 2026-08-11

## Top Story
According to a **[cnbeta report on the AI data center war in Ulanqab](https://www.cnbeta.com.tw/articles/tech/1572718.htm)**, Chinese tech companies are rapidly pivoting from renting cloud-based GPU compute to establishing large-scale, strategic physical data centers in this Inner Mongolian city. Benefiting from local electricity price advantages, abundant green energy, and 100-day modular containerized "方舱" designs, this shift introduces an AI-era "new Foxconn" model. This rapid, supply-chain-driven deployment of AI infrastructure provides Chinese AI developers with highly optimized token costs, fending off Western infrastructure projects that face multi-year construction delays.

## Tech & AI
In code intelligence, **[DeepSeek's new Harness team](https://www.cnbeta.com.tw/articles/tech/1572688.htm)** is reportedly building specialized code agents to directly challenge Anthropic's Claude Code. This development follows incredible news that an **[unreleased Claude model advanced Riemann Hypothesis research](https://www.cnbeta.com.tw/articles/science/1572708.htm)** by spawning 60 subagents to run 2400 shell commands and script hundreds of trials. Meanwhile, Anthropic is managing compliance by secretly deploying globally-applied invisible watermarks and C2PA file signatures, as detailed in a **[cnbeta report on Claude's new hidden watermarks](https://www.cnbeta.com.tw/articles/tech/1572682.htm)**, which has raised user tracking concerns.
