## Engineering & Dev
**[Next.js 16.2 Released with 4x Development Speed and AI Agent Tools](https://www.infoq.cn/article/NWjH4oTh0j4HsxJsCRaf)** Vercel has released Next.js 16.2, which boosts `next dev` startup speeds by 400% and increases HTML rendering speeds by 25% to 60% through optimizations in JSON parsing. The release also heavily caters to AI-assisted coding by auto-generating an `AGENTS.md` file and routing browser errors directly to the terminal so local AI coding agents can seamlessly read them.

**[Alibaba Open Sources AI Code Review CLI](https://www.ifanr.com/1668239)** Alibaba Group introduced Open Code Review, an open-source AI-driven terminal tool that evolved from its internal code review assistant. It utilizes a hybrid architecture of deterministic engineering for file management and an AI agent for dynamically searching codebases and providing line-level structural feedback.

**[Shanghai AI Lab Scientist Hu Xia on Agent OS Security at AICon](https://www.infoq.cn/article/ztM2hNuC8cfwT6FT7cGb)** As AI agents enter production, system stability, coordination, and governance have become paramount. At the upcoming AICon 2026 Shanghai, Shanghai AI Lab Lead Scientist Hu Xia will detail the "Shuan" Agent Operating System, a framework designed to embed security-as-a-service through system isolation and behavioral constraints.

**[FumaCRM Product_field.aspx SQL Injection Vulnerability](https://mrxn.net/jswz/fumacrm-Dingding-Product-Product_field-sqli.html)** A critical SQL injection flaw was discovered in the SaaS platform FumaCRM by Shanghai Fumeng Software. Unauthenticated remote attackers can exploit the `Product_field.aspx` interface to extract user data or even inject trojans to take complete control of the server.

**[Run 600 Classic Operating Systems in the Browser](https://www.ifanr.com/1668239)** Developer Andrew Warkentin created The Virtual OS Museum, an archive housing over 1,700 applications and 600 distinct operating systems dating back to 1948. Available as a massive 121GB offline download or a 14GB dynamic client, the project emulates obscure historical systems like A/UX, BeOS, and Plan 9.

## News & Commentary
**[Tencent Chief AI Scientist: The Second Half of AI is About Finding the Right Problems](https://www.ifanr.com/1668239)** During a cloud summit, Tencent's Chief AI Scientist Yao Shunyu argued that AI methodology is now largely mature, shifting the industry bottleneck to finding valuable use cases. Yao framed large models as universal hammers, emphasizing that Tencent's vast product matrix provides the necessary "good problems" and real-world context to build effective coding agents.

**[Douyin VP Responds to AI Mushroom Poisoning Incident](https://www.ifanr.com/1668239)** After a user claimed the AI assistant Doubao misidentified a toxic mushroom and caused a poisoning, Douyin VP Li Liang clarified that the AI had actually warned that the mushroom could be a highly toxic lookalike and strongly advised against eating wild fungi. He stressed that AI responses involving physical safety remain strictly referential and cannot replace human caution.
