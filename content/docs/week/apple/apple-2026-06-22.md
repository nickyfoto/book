## Articles Worth Reading

**iOS 27 Adds Mac-Like Recovery Mode for iPhone and iPad** ([MacRumors](https://www.macrumors.com/2026/06/22/ios-27-adds-mac-like-recovery-mode/))
iOS 27 introduces a new, independent recovery environment that can be accessed by holding the power button during boot. Much like the recovery mode on Apple silicon Macs, this interface allows users to install software updates, erase all content, or run diagnostics without ever connecting the device to a computer. This feature is expected to be a lifesaver for devices stuck in boot loops or experiencing failed beta updates, letting users independently resolve critical software issues via the on-device Recovery Assistant.

**Apple Dropping AirPort Utility From the App Store With iOS 27** ([MacRumors](https://www.macrumors.com/2026/06/22/apple-airport-utility-ios-27/))
Apple's latest developer release notes confirm that the AirPort Utility app is being permanently removed from the App Store. While users who have already downloaded the app can reinstall it, Apple explicitly warns that its functionality is no longer guaranteed on iOS 27 or macOS Golden Gate. Combined with the impending removal of AFP file-sharing support in macOS, this move signals the final nail in the coffin for Apple's discontinued AirPort Time Capsule hardware.

**iOS 27 beta 2 includes Write with Siri, the new version of Apple Intelligence writing tools** ([9to5Mac](https://9to5mac.com/2026/06/22/ios-27-beta-write-with-siri/))
The standalone "Writing Tools" interface from earlier iOS 18 beta versions has been entirely replaced by a more cohesive "Write with Siri" feature. Users can now rely on natural language processing to tell Siri exactly how to rewrite, proofread, or generate text directly from the keyboard. The newly integrated system uses your personal context to refine its outputs and includes a helpful before-and-after review panel for seamless document editing.
